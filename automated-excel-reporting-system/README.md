# Automated Monthly Reporting System

## Project Overview

This project is an automated Excel reporting solution developed using retail sales data.

The reporting system was designed to transform recurring monthly sales files into a structured management report while reducing the manual work required to prepare, consolidate, and analyze new reporting periods.

The goal was to create a repeatable reporting process in which new monthly data could be incorporated through Power Query and automatically reflected throughout the underlying analysis and management-facing report.

## Business Objective

The reporting solution was designed to help business stakeholders answer questions such as:

- How did the most recent month perform?
- How has performance changed compared with the previous month?
- Which product categories are contributing the most revenue?
- Which store locations are performing the strongest?
- Which products are currently driving sales?
- Where are meaningful increases or decreases occurring?
- How can recurring monthly reporting be completed with less manual preparation?

---

## Reporting Process

The solution follows a repeatable reporting workflow:

**Monthly Sales Files → Power Query → Consolidated Dataset → PivotTables → Reporting Logic → Management Report**

Power Query is used to combine recurring sales files and prepare the data for analysis. PivotTables and supporting formulas provide the analytical backend, while the final management report presents the most important information in a concise format.

## Reporting Approach

The solution was designed to separate data preparation, analysis, and presentation.

Power Query handles recurring data consolidation, PivotTables provide a flexible analytical layer, and formulas translate the underlying analysis into a consistent management report.

This allows the reporting process to be updated as new monthly files become available without manually rebuilding the report each period.
