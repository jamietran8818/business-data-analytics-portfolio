# Global Retail Performance Dashboard

## Project Overview

This project is a multi-page Power BI reporting solution developed for a fictional global electronics retailer.

The dashboard was designed to provide executive-level performance monitoring while allowing users to investigate revenue, profitability, product performance, geographic markets, and customer behavior in greater detail.

The goal was to create a reporting solution that allows users to move from high-level performance indicators to more detailed analysis without overwhelming the initial executive view.

## Business Objective

The reporting solution was designed to help business stakeholders answer questions such as:

- How is the business currently performing?
- How have revenue and profit changed compared with previous periods?
- Which products and categories are driving performance?
- Which geographic markets are contributing the most revenue?
- How does performance differ between physical stores and online sales?
- Which customer segments contribute the most value?
- Where are there significant changes or trends that may require further investigation?

## Reporting Approach

The report was designed using a layered approach.

The Executive Overview focuses on the most important indicators needed for regular performance monitoring. Additional report pages allow users to investigate specific areas of the business when additional context is needed.

This structure keeps the primary reporting experience concise while preserving the ability to perform deeper analysis.
